# Dark mode and handling feature requests

## Current appearance options
CloudDesk follows the operating system setting for light and dark appearance in the desktop apps. The web app offers a light theme and a high contrast theme in Settings, Appearance. A full dark theme for the web app is not available yet.

## Logging the request
Feature requests are not defects. Record the request, the customer's use case in a sentence and the plan they are on. Link the ticket to an existing request if one exists, so that the product team can count demand. A request has low severity unless the customer says it blocks their work.

## What to say about the roadmap
Do not promise dates or features. It is fine to say that the request has been recorded and shared with the product team, and that announcements about new features appear in the product release notes.

## Workarounds
For dark mode, suggest the desktop app with the system dark setting. For other requests, look for an existing feature that meets the need and describe it.

## Closing the ticket
Once the request is logged and the customer informed, the ticket can be resolved. Invite them to reply if the missing feature is blocking an important task, in which case the ticket is reviewed again.
