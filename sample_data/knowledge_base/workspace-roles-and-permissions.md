# Workspace roles and what each can do

## The four roles
Each member of a workspace has one role. Owners control billing and can delete the workspace. Admins manage members, sharing policy and integrations. Editors create and change files. Viewers can only read and comment. A workspace always has at least one owner.

## Folder permissions
A folder can be shared with a narrower group than the whole workspace. A person with the Editor role may still see "You do not have access" on a private folder if nobody has added them. The folder owner or an admin can add them from the Share dialog.

## Changing a role
Admins open Settings, Members and choose the new role from the list next to the person. The change applies at once. Only an owner can create another owner, and the last owner cannot be demoted.

## Common questions
A member who cannot invite colleagues is probably an Editor, because only admins and owners can invite. A member who cannot see billing is not an owner. Support should confirm the role from the member list before explaining which action is available.

## Limits for support
Support can explain roles but cannot change them. An admin of the workspace must make the change, and ownership transfers need confirmation from the current owner.
